# SonusID – Şarkı Tanıma Web Uygulaması

Bu proje, mikrofon aracılığıyla ortam sesini yakalayıp AudD API’siyle şarkı tanıma, dinamik analiz ve öneri listeleri sunar.

## 📦 Live Demo
Uygulamayı doğrudan şu adresten deneyebilirsiniz:

https://sonusid.vercel.app   <!-- Vercel dağıtım URL’nizi buraya ekleyin -->

> **Not:** Tarayıcınız mikrofon izni ister; izin verdiğinizde “Dinle” butonuyla şarkıyı tanıyabilirsiniz.  
> AudD API anahtarını sağ üstteki **“API Anahtarı Gir”** butonundan eklemeyi unutmayın.

---

## 🚀 Yerel kurulum (geliştiriciler için)

```bash
npm install          # bağımlılıkları kur
npm run dev          # geliştirme sunucusunu başlat
```
